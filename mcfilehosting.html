Monte Carlo Event Files

Loading multi-generator events into NUISANCE is straight-forward, but it can be time-consuming to create the multiple generator event files needed for a single comparison.

NUISANCE doesn't handle event generation, but we have containers with a number of generators installed, scripts to generate events, and tutorials. For more info, see the tutorials page.

We host terabytes of generated events for different experiments and their running configurations for different generator in the "NUISANCE flat-tree format", listed here:

  • 2025 IOP review
  • 2023 IOP review
  • 2019 Pittsburgh tensions
  • 2016 NUISANCE MC for paper
For information on how to use NUISANCE flat trees, see the the tutorials page.
